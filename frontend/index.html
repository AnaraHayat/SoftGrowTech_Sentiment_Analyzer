How a sentence becomes a verdict

Three steps, in the order the text actually travels through the system.

01 / clean

Normalize the text

Lowercase it, strip punctuation and numbers, collapse whitespace. This keeps the model focused on words, not formatting noise.

02 / vectorize

TF-IDF, unigrams + bigrams

Text becomes a sparse vector of up to 8,000 weighted word and word-pair features, with common stopwords removed.

03 / classify

Logistic Regression

The vector is scored against a model trained on labeled reviews, returning a label plus a probability for each class.

On the dataset source: this build uses NLTK's built-in movie_reviews corpus — 2,000 hand-labeled positive/negative reviews, the same underlying review data behind many Kaggle "IMDB movie review sentiment" datasets. To swap in a Kaggle dataset directly, download its CSV, save it as backend/data/dataset.csv with a text column and a sentiment/label column, and re-run train_model.py — the pipeline reads either format automatically.
